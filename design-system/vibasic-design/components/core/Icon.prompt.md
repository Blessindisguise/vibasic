Line icon (Lucide set, angular square-cap rendering) — use for every icon in Vibasic; never emoji.
```jsx
<Icon name="scan-barcode" size={20} />
<Icon name="triangle-alert" size={16} title="Cảnh báo" />
```
- Sizes: 13–14 in badges, 16 in desktop controls, 18 in nav, 20–28 in warehouse/touch.
- Inherits `currentColor`. Available names: `ICON_NAMES` (dashboard, package*, boxes, scan-barcode, barcode, clipboard-*, triangle-alert, lock, truck, factory, printer, …).
